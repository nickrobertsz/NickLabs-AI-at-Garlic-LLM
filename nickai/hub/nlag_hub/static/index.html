Ports

The console must be jailbroken and running an FTP server (GoldHEN: enable the FTP server, port 2121). Add as many consoles as you own; each one is an independent server.

Models on your computer

Models converted for the consoles. Pick a console and send; it is checked and installed there, then load it from the Consoles page.

Add a model

From your Ollama

Models already downloaded with Ollama on this computer are converted, with no new download. Only Qwen3.5 models work (the Garlic engine runs that family).

Download an Ollama model

From HuggingFace

A console keeps the whole model in its GPU memory: about 4.6 GB of weights fit (Qwen3.5 up to 4B, plus the 9B build shipped with the app). Bigger models are refused with an explanation.

Jobs

Each chat talks to the console you choose and speaks as its own agent. One console answers one request at a time; different consoles answer at the same time.

Who is speaking

Agents are named by the X-Agent-Id header (or the OpenAI user field). A console serves one agent at a time and rotates between waiting agents; consoles run in parallel.
